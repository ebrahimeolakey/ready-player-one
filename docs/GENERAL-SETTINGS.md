# 通用设置

本页描述 0.4.6-beta.1 的通用偏好。

设置 → 通用提供会话布局、对话密度、隐藏空编辑器、系统通知及分类、菜单栏 / 托盘图标、完成提示音和启动更新检查。保存后生效，保存在本机加密 `client.json.enc`。关闭通知总开关保留各类别选择；提示音独立，默认关闭。菜单栏图标默认关闭。恢复默认会写入并应用默认值。

布局的具体行为和真实组件验证见 [会话偏好](STUDIO-PREFERENCES.md)。通知去重、权限和平台限制见 [桌面通知](DESKTOP-NOTIFICATIONS.md)。这些设置不会改变 Provider 账号、会话角色或审批权限。

关闭“启动时检查更新”仅停止下次启动的自动检查，仍可在更新面板主动检查、下载和安装。不会自动下载或安装更新，也不会取消已经开始的用户操作。

设置输入在主进程进行白名单校验，存储写入失败会恢复内存原值；无关的 Hub 状态广播不覆盖尚未保存的设置草稿。原生通知 / 托盘操作失败会显示错误，已经成功持久化的偏好仍保留。操作系统可能限制通知展示，应用不会声称投递成功即代表用户已经看到通知。关闭窗口仍会退出应用，图标开关不改变后台运行或共享房间的存活方式。

验证入口：`tests/general-settings.test.mjs`（输入边界）、`scripts/general-settings-desktop-smoke.mjs`（真实 main/preload/React 保存、无关广播、无效输入、磁盘写失败回退及第二个进程恢复）；后者先运行 `npm run build`，使用隔离临时目录和失败账号二进制，不调用真实模型或修改已安装应用。
