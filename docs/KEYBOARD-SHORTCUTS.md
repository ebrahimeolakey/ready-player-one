# 快捷键

设置 → 快捷键。点击某个组合键后按下新组合，自动保存；可停用单个动作或恢复默认。配置仅保存在本机加密设置中。

| 动作 | Mac 默认 | Windows / Linux 默认 |
| --- | --- | --- |
| 搜索会话 | ⌘K | Ctrl+K |
| 新建 Agent | ⌘⇧L | Ctrl+Shift+L |
| 展开 / 收起终端 | ⌘J | Ctrl+J |
| 查找文件 | ⌘P | Ctrl+P |
| 发送任务 | ⌘Enter | Ctrl+Enter |
| 保存文件 | ⌘S | Ctrl+S |
| 停止当前 Agent | Esc | Esc |

关闭弹窗固定为 Esc。终端聚焦时应用不抢占这些键；编辑器保存只针对当前文件，发送/停止只针对当前输入框所属的 Agent。中文输入法组合期间不触发快捷键；按住按键不会连续重复执行。

设置拒绝动作间重复绑定、保留的系统/编辑组合和不支持的按键。非停止动作需要包含 ⌘ 或 Ctrl（Windows/Linux 不接受 Windows 键）。捕获设置时按 Tab 可退出，保持键盘导航可用。

2026-09-24 验证：纯逻辑回归覆盖默认、平台差异、IME、重复事件、冲突、停用和校验。真实 Mac 桌面将搜索从 ⌘K 改为 ⌘⇧F，旧键不再触发，新键打开搜索；关闭并重启隔离应用后仍生效，随后恢复默认。Windows 组合键行为目前为自动化验证，未做实体键盘交互验收。
