# 原版界面实测补充

2026-09-24 在本机运行中的 Amoeba 0.1.38，通过原生界面观察；没有修改原版设置、启动 Agent 或复制项目内容。这里记录的是实际可见入口，不代表头号玩家已全部实现。

## 会话列表

窄侧栏、居中顶栏品牌、搜索与排序、白色「新建」按钮。会话卡片显示名称、空闲状态、Provider 和成员头像。空闲列表没有三个零值统计块。本轮 Mission Control 据此隐藏全零统计；非零文件活动可折叠查看来源。

## 提供商

二级设置侧栏；每个 Provider 一行，左侧图标和名称，右侧安装按钮或连接状态。原版显示 Claude、Codex、Cursor、Antigravity、OpenCode 和自定义入口。头号玩家原生支持 Codex/Claude，其他供应商走已明确实现的 ACP/兼容 API，不能把这些入口当作原版所有适配器的等价实现。

## 编辑器

原版分三组：

- 字体：字体名、字号、行高、连字。
- 格式：缩进宽度、空格代替 Tab、保存时格式化、去掉行尾空白。
- 显示：自动换行、空白字符、缩进参考线、小地图。

原版可见默认值为 IBM Plex Mono、12.5、1.6、2 空格；连字、空格缩进、保存格式化、去行尾空白、缩进线、小地图开启，换行与空白字符关闭。本项目新增保存转换须主动开启，避免首次保存改变已有文件；格式化语言范围必须明确。

## 通用偏好：实际观察到、需逐项补齐

原版显示：自动检查更新；从 VS Code 导入设置/扩展/快捷键；重置内置提示；Vibecoder/Editor 默认布局；对话详细程度；diff 审阅按钮位置；小地图与成员写入位置；空编辑器自动隐藏；聊天作为编辑器标签；深/浅主题；成员颜色；启动时打开上次会话；系统通知及审批/接管/结果未知分类开关；菜单栏图标；完成声音；登出。

当前源码中的自动检查、系统通知和双栏工具，不等于上述全部偏好已经提供。特别是扩展导入、成员写入位置标记、主题、托盘及分类通知，仍需独立实现/验收。不要把旧 UI 对照文档或某个设置截图写成全状态 1:1 证明。
