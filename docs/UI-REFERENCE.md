# v0.3 界面对照

依据：2026-09-24 本机实际运行的 Amoeba 0.1.38。逐页观察会话列表、新建会话、People、提供商设置、会话编辑器 / Agent / 成员栏以及 Share 侧栏，并读取安装包中的布局尺寸和颜色参数作对照。没有复制其 JavaScript 实现、私有数据或品牌图形。

## 已重做的页面

| 原版结构                         | 中文实现                                                |
| -------------------------------- | ------------------------------------------------------- |
| 38 px 顶栏、224 px 窄侧栏        | 顶栏仅保留「头号玩家」；会话 / 成员 / 工作区 / 头像设置 |
| Sessions 紧凑卡片                | 名称、状态、提供商、成员；搜索 / 排序 / 新建            |
| New session 居中弹窗             | 工作区选择、任务名称、开始会话                          |
| 文件树 + 上方编辑器 + 下方 Agent | 项目文件搜索、CodeMirror、可调整高度的 Agent / 终端     |
| 右侧 Session / Environment       | 成员通道、计划、评论、审批；目录、worktree、导出、归档  |
| New pane                         | 第二会话并排打开，关闭后恢复文件树与成员栏              |
| Share 右侧抽屉                   | 网络选择、复制邀请、成员、撤销；范围说明默认折叠        |
| People 成员行                    | 工作区选择、在线成员、邀请                              |
| Settings 二级侧栏                | 通用、提供商、GitHub、快捷键、网络、数据                |

色彩采用中性黑灰与白色主按钮，Agent 输入框保留绿色边线。去掉宣传标题、统计总览、装饰插画、功能介绍段落和重复说明；账号与运行详情折叠，图标按钮提供 tooltip / 无障碍名称。品牌名称与图标仍属于头号玩家。

## 验收与边界

已在真实 Electron 窗口中验证创建会话、添加 Codex 通道、提交并拒绝测试审批（未运行模型）、搜索并打开 src/Studio.tsx、第二会话并排显示及关闭恢复、归档测试会话、账号状态和分享入口。文件搜索另有临时目录测试，包含嵌套文件、忽略目录和符号链接边界。

本轮对照的是以上已观察的核心页面。未宣称所有原版状态逐像素等价：原版组织权限、企业设置、其他提供商、内置网页浏览器、完整 IDE 调试与扩展 UI 尚未覆盖。网络分享与账号接入采用本项目真实能力，不展示不存在的可用操作。
