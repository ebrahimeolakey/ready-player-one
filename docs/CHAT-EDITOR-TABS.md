# 聊天作为编辑器标签

通用设置「聊天作为编辑器标签」新增 `openChatsAsEditorTabs: boolean`，本项目默认开启。这参考已安装原版 0.1.38 的当前开状态，是本项目的默认值选择，**不是原版出厂默认的证据**。

## 对象与入口

本项目将每个 Agent lane 的共享聊天作为标签对象。本人及当前会话中可见的其他成员聊天均可打开，不创建新的 Provider session。原版 General 有该偏好的直接证据，但进一步打开原版会话时 CUA 窗口/可访问性树不一致，未能可靠确认其具体聊天对象和入口。因此这里明确是本项目设计，不宣称原版对象映射已 1:1 实证；群聊和跨全局会话标签不在本功能范围。

- 开关开启：点击成员面板中的 Agent 聊天，在编辑器中打开或聚焦该 lane 标签。
- 开关关闭：尚未打开标签的聊天进入下方 Agent 面板；已打开的标签仍可聚焦，不因切换偏好而被关闭。
- 聊天页头「在编辑器中打开聊天」始终可用，不受默认打开位置偏好影响。
- 同一 lane 重复打开只聚焦，不创建重复标签。显示名称和 Provider 来自实时授权快照，内部目标使用工作区/会话/连接身份和 lane ID，不用姓名或 Provider 名作身份。
- 「文件」标签恢复原文件编辑器。点文件树也会回到文件界面，包括需要处理未保存改动确认的情况。
- 关闭聊天标签只移回下方聊天面板，保留聊天记录、未发送正文和附件；不调用停止、接管、删除、重跑或新建 Provider 会话。其他标签继续存在。

## 工作目录与状态

聊天选择与本机工作目录分离。点击聊天标签或成员聊天不会切换文件/终端路径；下方页头「本机工作目录」明确选择会话目录或本人的 Agent 工作目录，沿用现有本机映射。其他成员不能成为本机工作目录目标。

`ChatViewPortal` 为每个已访问 lane 创建一个固定 DOM 容器，React portal 始终使用该容器。改变位置只移动同一容器，不重挂载 AgentLane；未显示的聊天仍保持实例，继续接收授权快照。原 CodeMirror 与终端也持续挂载，聊天层不会覆盖文件草稿或重启 PTY。

标签列表只属于当前 Studio 生命周期。离开会话、关闭分栏或重启后不恢复标签列表；原有加密 composer/文件草稿仍按现有规则保存。切换连接身份会清除当前标签视图，不把旧标签目标带到新房间。这里不新增跨会话 keepalive，不承诺保留离开会话前的所有界面展开状态或终端实例。

## 权限与副作用

- 他人聊天只展示共享消息，不显示发送框，也不读取/写入该 lane 的本机 composer，不订阅本机语音。
- 本人 lane 的发送/语音及伙伴停止入口遵循当前工作区 Editor/Owner 权限；降为只读后不能通过该视图发起执行，草稿不清除。实际执行仍由原有主进程和 Hub 授权。
- 打开、切换、关闭标签和切换偏好均不调用 `run.*`、`lane.stop`、Provider 启动、接管或审批。
- `useComposer(laneId, enabled)` 禁用时不注册草稿订阅、不读写本机 model；启用后的异步加载绑定当前 lane 与启用状态，旧加载结果不能进入另一 lane。已加载的本人草稿与未完成保存队列仍沿用现有加密机制。
- 此功能未迁移原有 ComposerStore 的 laneId 存储键；它不声称重构了所有跨房间草稿命名空间。

## 验证

- `tests/chat-editor-tabs-view.test.mjs`：真实 Electron + Studio/AgentLane/CodeMirror/xterm，三个 lane（含他人成员）、多个标签、重复聚焦、同一个 DOM 与输入节点跨位置复用、实时消息继续更新、偏好关闭与显式打开、关闭回面板、文件脏内容与终端保留、工作目录不变、只读降权、删除 lane、连接切换、700 像素窄窗口、跨会话已保存草稿，并审计没有执行方法调用。桥响应使用合成数据，不调用真实模型。
- `tests/composer-hook-view.test.mjs`：真实 React hook，禁用→启用、换 lane、迟到加载、有效缓存重新启用、同 lane 多视图初次加载去重、禁用无 IO、不向其他 lane 保存。
- 现有 composer 加密/崩溃恢复/附件/并行草稿冲突测试继续通过；Studio 原偏好测试确认编辑器和终端不被布局切换重建。
- `scripts/general-settings-desktop-smoke.mjs`：真实 main/preload/React，关闭此开关保存后重启保持，恢复默认后开启；只用临时加密数据与失败的 Provider 账户探测 stub。

Mac 实际组件和桌面持久化验收；Windows/Linux 的标签视觉交互仍待对应平台验收。随 0.4.8 源码批次集成，安装包发布状态以 README 为准。
