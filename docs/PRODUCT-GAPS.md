# 面向运营、FDE 与轻开发团队的覆盖情况

核对版本：0.3.0-beta.1，2026-09-24。以下是当前实现与产品建议的对照，不代表功能已完成或承诺发布日期。

产品目标：让同事围绕一件工作，共享资料、拆解任务、调用 AI、交付结果并持续跟进。活动运营、客户交付与项目管理是主要场景，代码编辑是其中一种工具。

## 已有基础

- 多人共享 AI 会话、执行前审批、实时讨论、共同待办、共享记忆。
- 本机 Codex / Claude 官方登录，以及用于仓库访问的 GitHub 授权。
- 跨互联网的临时邀请、撤销、会话归档和 JSON 导出。
- 普通本机文件夹已经能打开；文本编辑与搜索可用。Git 并非打开目录的硬性条件，但界面仍使用「仓库」等开发术语，Git 功能需要 Git 环境。

## 先补齐日常工作的闭环

| 优先级 | 能力 | 现在 | 尚未覆盖 / 建议验收标准 |
| --- | --- | --- | --- |
| P0 | 非开发者入口 | 编辑器、Agent、终端为主；已有普通文件夹支持 | 默认展示任务、资料、交付物；无需理解 Git、分支或终端即可完成一次任务；开发工具按需展开 |
| P0 | 场景模板 | 通用会话和勾选清单 | 活动筹备、客户交付、项目推进三类模板；创建后立即得到可编辑的步骤和预期产出 |
| P0 | 资料与交付物 | 本机文本文件；共享消息和显式发布的代码 diff | 拖入文档、图片、表格；让同事可按权限预览、下载实际文件；版本与来源可追溯；仅出现在对话里的路径不能算交付 |
| P0 | 可跟进的任务 | 清单只有文本、创建者、完成状态 | 可指定或调整负责人、截止日期、任务状态，显示逾期项；关联会话和交付物；清单创建者不等于可分配的负责人 |
| P0 | 同事安装与验收 | Apple Silicon / Intel ZIP、官方登录入口 | Mac 签名与公证、清晰的安装诊断；在两台实体 Mac、不同网络、新账号上完成实际协作验收 |
| P1 | 办公文件体验 | 文本编辑器与 JSON 导出 | PDF、Word、Excel、PPT、图片预览；AI 生成文件有明确完成状态、打开与导出入口；不能把 CLI 理论上能生成文件视为产品已经支持 |
| P1 | 日常软件连接 | GitHub 授权 | 根据团队实际工具接入飞书 / Notion / 日历 / 网盘等，支持官方授权和导入；对外发送、发布或修改前让用户确认具体内容 |
| P1 | 持续协作与访客 | 房主在线、临时公网通道；工作区邀请 | 固定入口、离线查看、恢复协作、成员身份稳定；只读访客与成员分级，适合邀请客户或外部供应商 |
| P1 | 跟进与通知 | 手动运行、手动查看 | 到期提醒、定时汇总、任务完成通知、失败重试提示；不要重复执行已经有副作用的任务 |
| P1 | 使用与维护 | 本机账号状态、错误输出 | 额度或失败原因清晰可见、诊断导出、版本更新提醒与更新流程；账号已登录不等于任务一定可运行 |

P0：直接影响同事能否完成首个实际任务。P1：首轮试用后按阻碍程度补齐。其中，文件共享需要同时设计传输方式、存储位置和访问权限；不能仅增加一个上传按钮。

## 三类场景具体还缺什么

### 活动运营

已有会话可讨论方案和维护清单。专用活动时间线、预算表、物料清单、供应商跟进、报名 / 签到与复盘指标尚未实现。

建议首个模板先覆盖「方案 → 分工 → 物料 → 执行清单 → 复盘」，报名、签到等优先连接已有工具，避免首轮重建完整活动平台。

### FDE / 客户交付

已有共享 Agent 过程、本机脚本执行和讨论。客户资料归档、需求到验收项的映射、环境连接管理、交付包、客户只读访问、验收记录尚未实现。

建议首个模板覆盖「需求 → 复现 / 排查 → 方案 → 交付物 → 验收」，不同客户使用独立工作区，并补齐外部成员权限。

### 项目管理

已有勾选清单和会话归档。负责人分配、截止日期、看板、里程碑、依赖关系、进度汇总和提醒尚未实现。

先实现负责人、截止日期、状态与周报，再根据使用情况增加看板或日历；无需第一轮建设复杂甘特图。

## 与原版的差距如何排优先级

核心界面已经参照原版重排，尚未做到所有页面和状态的 1:1。对上述用户，建议保留简洁的布局与操作习惯，将默认内容调整为任务、资料和结果。

完整 VS Code 扩展、LSP、调试器、交互式终端、字符级协同代码编辑、Provider 原生 session 迁移、逐工具远程审批、更多 Provider 和企业云端组织管理仍未覆盖。它们不应全部成为运营试用的前置条件；先验证真实业务任务，再补实际需要的能力。

建议下一轮顺序：简化任务入口与三类模板 → 资料 / 交付物共享 → 负责人 / 截止日期 / 状态；签名与双机验收同步推进。常驻服务和外部访客权限按团队试用反馈决定方案。
